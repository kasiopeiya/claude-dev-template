# 仕分け台帳：会員ポイント管理システム

> [!NOTE]
> 本書は `docs/project-context/requirements-triage.md`（仕分け台帳）の**記述サンプル**である。台帳を書く・レビューする AI が、1行の粒度と `行き先` の書き方を掴むために読む。題材は [要件定義書のサンプル](requirements.md)と同じで、その「背景・入力元」に挙げた入力資料の記述を仕分けている。列と `仕分け` の値の正典は Rule [requirements-doc.md](../../.claude/rules/requirements-doc.md) であり、本書はそれを再掲しない。
> 要件定義書のサンプルは凍結済みなので、`未決` の行は無い。
> このサンプル固有の判断は次のとおり。
>
> - 入力資料の1文を1行にする。1文が複数の要件に入ったときも行を割らず、`行き先` に `, ` で区切って並べる
> - 入力資料ごとに節を分け、`ID` は節をまたいで通し番号にする

## 入力資料と台帳の行

- RFC「ポイント統合基盤 要求メモ v1.2」：TR-01〜TR-17
- 現行運用ヒアリング議事録：TR-18〜TR-28
- 個人情報取扱規程（顧客社内）：TR-29〜TR-34

## RFC「ポイント統合基盤 要求メモ v1.2」

| ID    | 入力資料の記述                                                                                  | 仕分け   | 行き先                                                                                     |
| ----- | ----------------------------------------------------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------ |
| TR-01 | 店舗と EC を横断してポイントを管理し、会員の再来店・再購入を促したい。                          | 採用     | 目的                                                                                       |
| TR-02 | 店舗と EC で別々に貯まっているポイントを1つの残高にまとめ、どちらでも合算して使えるようにする。 | 採用     | F-01, F-02, AC-07                                                                          |
| TR-03 | EC と POS の購入確定を受け取り、その都度ポイントを付与する。                                    | 採用     | F-01                                                                                       |
| TR-04 | ポイントは税抜購入金額100円につき1ポイントとする。                                              | 採用     | BR-01                                                                                      |
| TR-05 | ギフト券・送料は付与の対象に含めない。                                                          | 採用     | BR-02                                                                                      |
| TR-06 | ポイントの有効期限は付与から1年とする。                                                         | 採用     | BR-03                                                                                      |
| TR-07 | ポイントを使うときは、期限の近いものから使う。                                                  | 採用     | BR-04                                                                                      |
| TR-08 | 期限切れのポイントは毎日自動で失効させる。                                                      | 採用     | F-03                                                                                       |
| TR-09 | 失効の前に、会員へメールで知らせる。                                                            | 採用     | F-06, BR-08                                                                                |
| TR-10 | 会員がスマホで残高と履歴を確認できるようにする。                                                | 採用     | F-04, BR-10                                                                                |
| TR-11 | 会員番号は EC サイトが発番する10桁の番号をそのまま使う。                                        | 採用     | AC-01                                                                                      |
| TR-12 | 付与の計算に誤りがあってはならない。                                                            | 採用     | 非機能要件：SLI（指標）／付与正確性                                                        |
| TR-13 | セール期間中も、レジでの付与・利用が待たされないこと。                                          | 採用     | 非機能要件：B. 性能・拡張性／ピーク時の業務量                                              |
| TR-14 | 現行の Excel 台帳の残高を新しい仕組みに引き継ぐ。                                               | 採用     | 非機能要件：D. 移行性／移行の要否・対象, 制約と前提：既存 Excel 台帳を初期データとして移行 |
| TR-15 | 将来は会員ランクに応じて付与率を変えたい。                                                      | 延期候補 | スコープ外：会員ランク制度・ランク別付与率                                                 |
| TR-16 | 貯まったポイントでキャンペーン抽選に応募できるようにしたい。                                    | 非対応   | スコープ外：ポイントを使ったキャンペーン抽選                                               |
| TR-17 | 他社ポイントと相互に交換できるとよい。                                                          | 非対応   | スコープ外：他社ポイントとの相互交換                                                       |

| ----- | -------------------------------------------------------------------------------- | ------ | ----------------------------------------------- |

| TR-20 | 残高を聞かれても店舗の台帳を見ないと答えられず、折り返しの電話になる。           | 採用   | 解決する課題：CS 部門, F-04                     |
| TR-21 | 同じレシートで2回ポイントが付いたという問い合わせが、月に数件ある。              | 採用   | BR-07                                           |
| TR-22 | ポイントで代金を払った分にまでポイントが付いていたことがある。                   | 採用   | BR-02                                           |
| TR-23 | 残高より多いポイントを使えてしまい、マイナスになった残高を手で直したことがある。 | 採用   | BR-05                                           |

| TR-28 | 苦情の受付は、これからも電話で人が聞きたい。                                     | 採用   | 業務一覧：苦情一次対応                          |
