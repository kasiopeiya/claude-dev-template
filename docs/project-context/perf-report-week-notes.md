# 実績レポートの週の説明

実績レポートの週次の図に載せる説明を、人間が週ごとに書く。作業の内容は GitHub の記録から確実には出せないので、AI が記録から推測して説明を書くことはしない。読むのは [/perf-report](../../.claude/skills/perf-report/SKILL.md) である。

## 書き方

- 説明を残したい週だけ、下の表に1週1行で足す。行が無い週は、レポートで空欄になる
- `週の月曜` には、その週の月曜の日付を `YYYY-MM-DD` で書く。週は日本時間の月曜始まりで、月曜以外の日付はどの週にも当たらない
- レポートの期間の外にある週の行は、読まれない
