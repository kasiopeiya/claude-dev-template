# 用語集

プロジェクト内で使う用語の単一の真実（SSOT）。LLMにコンテキストとして渡すため、**LLMが一般知識だけでは正しく読めない語だけ**を載せる。下の表で載せるとした語は、各文書から本書にリンクし、再定義しない。

## 載せる語・載せない語

| 語の種類                                                               | 載せるか                                 | 定義に書くこと                                                                                              |
| ---------------------------------------------------------------------- | ---------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| 社内・プロジェクト固有の語（造語・社内略語・社内システム名・業務用語） | 載せる（すぐ下の行に当たる語を除く）     | 語の意味                                                                                                    |
| 用語定義の節を持つ文書の中だけで使う語                                 | 載せない（その文書の用語定義の節に置く） | —                                                                                                           |
| 一般語だが、社内で特殊な使い方や特筆すべき事項がある語                 | 載せる                                   | 社内での使い方・特筆事項だけ。一般的な説明は書かない（例：Apigee → 外部インターネットから社内基盤への窓口） |
| 一般的な意味のまま使う語                                               | 載せない                                 | —                                                                                                           |
