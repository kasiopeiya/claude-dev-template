# 用語集

プロジェクト内で使う用語の単一の真実（SSOT）。LLMにコンテキストとして渡すため、**LLMが一般知識だけでは正しく読めない語だけ**を載せる。各文書からは本書にリンクし、再定義しない。

## 載せる語・載せない語

| 語の種類                                                               | 載せるか | 定義に書くこと                                                                                              |
| ---------------------------------------------------------------------- | -------- | ----------------------------------------------------------------------------------------------------------- |
| 社内・プロジェクト固有の語（造語・社内略語・社内システム名・業務用語） | 載せる   | 語の意味                                                                                                    |
| 一般語だが、社内で特殊な使い方や特筆すべき事項がある語                 | 載せる   | 社内での使い方・特筆事項だけ。一般的な説明は書かない（例：Apigee → 外部インターネットから社内基盤への窓口） |
| 一般的な意味のまま使う語                                               | 載せない | —                                                                                                           |
