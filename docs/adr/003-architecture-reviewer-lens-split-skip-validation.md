# ADR-003: architecture-reviewer-agent のレンズ分割を、1体での取りこぼし検証なしに進める

## 決定（何を選んだか）

architecture-reviewer-agent を4レンズ（[ADR-002](002-architecture-reviewer-four-lenses.md)）に分けるにあたり、`docs/policy/review-subagent-lens-policy.md`「分けるかどうかは1体の取りこぼしで決める」はこのケースに適用しない。1体での事前検証を経ずに分割し、分けた効果（担当レンズが欠陥を拾うか）は実プロジェクトで `/arch-review` を運用しながら確かめる。

## 採用理由（なぜこれを選んだか）

同ポリシーが定める検証手順は、欠陥を仕込んだ対象に1体を3回掛けて取りこぼしを確かめるものだが、これは `samples/` のような検証用リポジトリで試しても、実プロジェクトの複雑さでの見落としが減るかどうかは測れない。人間が「分割する前提で進め、効果は実プロジェクトで確かめる」と決めた。

## 検討した代替案（なぜ却下したか）

**決定の軸：レンズ分割の前提条件（1体での取りこぼし検証）を、このケースでどう扱うか。**

| 案                   | 内容                                                                            | 却下理由                                                                        |
| -------------------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| 先に1体で3回検査する | ポリシー通り、欠陥を仕込んだ対象に1体の agent を3回掛けてから分割の要否を決める | `samples/` で試しても実プロジェクトでの見落とし減少効果は測れず、試す意味が薄い |
