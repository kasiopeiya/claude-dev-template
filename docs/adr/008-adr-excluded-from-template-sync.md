# ADR-008: `docs/adr/` を利用先への同期から外し、同期されるファイルからは ADR を URL で参照する

## 決定（何を選んだか）

`docs/adr/`（`docs/adr/adr-template.md` を除く）を、テンプレート同期スクリプト（`scripts/sync-template.sh`）の同期対象から外す。同期されるファイル（Markdown・ワークフロー等）からは `docs/adr/` 配下の ADR を相対リンクせず、テンプレートリポジトリの URL で参照する。この禁則は `npm run check:links` が機械的に検査する。

## 採用理由（なぜこれを選んだか）

利用先ではテンプレートのハーネスは補助的な位置づけで、テンプレートの ADR は利用先の ADR 判定基準（[adr-policy](../policy/adr-policy.md)）では ADR にしないものにあたる。そのまま同期すると、利用先の ADR 一覧にテンプレート固有の決定が混ざり、番号も衝突しうる。「同期されるファイルから ADR を相対リンクしない」は機械で判定できるので、文章の約束ではなく検査で守らせる。

## 検討した代替案（なぜ却下したか）

**決定の軸：テンプレートの ADR を利用先とどう分けるか。**

| 案                                              | 内容                                                                              | 却下理由                                                                                                                                   |
| ----------------------------------------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| ハーネスの ADR を別ディレクトリに置いて同期する | `docs/adr/` はプロジェクト固有、ハーネスの ADR は別ディレクトリに置く             | `/create-adr`・`scripts/generate-adr-index.mjs`・`.githooks/pre-commit` が `docs/adr/` を決め打ちしており、2か所を扱えるよう直す必要がある |
| リンク検査を新しいスクリプトとして作る          | `check-markdown-links.mjs` とは別に、ADR リンク専用の検査スクリプトを作る         | 恒久的に保守が要る資産の新設になる。CI を落とす原因は Markdown のリンク切れなので、既存のリンク検査の拡張で足りる                          |
| ポリシーに文章で書くだけにする                  | 「同期されるファイルから ADR を相対リンクしない」を規約として明文化するだけにする | 機械で判定できる決まりを文章だけで守らせることになり、破られても気づけない                                                                 |
