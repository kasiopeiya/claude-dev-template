# ADR-006: open な週次 docs 整合性チェック Issue があるときは、新しい週次 Issue を起票しない

## 決定(何を選んだか)

`scripts/doc-consistency-weekly-issue.mjs` は、専用ラベル（`doc-consistency-weekly`）が付いた open な Issue が既にあれば起票せず、無いときだけ起票する。

## 採用理由(なぜこれを選んだか)

処理待ちの週次 Issue は1件で足りる。起点を前回処理以降の変更に絞る改善（Issue #654）が入れば、処理が1週遅れても次回でその分を追いつけるため、未処理のまま複数積み上げる必要が無い。

## 検討した代替案(なぜ却下したか)

**決定の軸：未処理の週次 Issue が残っているとき、新しい週次 Issue をどう扱うか。**

| 案                                    | 内容                                                          | 却下理由                                                                       |
| ------------------------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| 毎週必ず起票する                      | 未処理の Issue があっても、週が来たら新しく起票する           | 未処理のまま複数積み上がり、どれを処理すべきか分かりにくくなる                 |
| 古い未処理の Issue を閉じて起票し直す | 未処理の Issue を close し、同じ内容の新しい Issue を起票する | 対象範囲（docs/ 全体）は変わらないため、同じ作業が並ぶだけで実質的な違いが無い |
