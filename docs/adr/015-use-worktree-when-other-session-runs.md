# ADR-015: 元のフォルダで別セッションが動いているときだけ、専用の worktree に入って作業する

## 決定（何を選んだか）

共有の作業ツリーで別セッションが `git switch` しても自分のコミットが動かないよう、必要なときだけ作業の場所を分ける。

- **作業場**：auto-programmer の専用 clone、メイン（元のフォルダ）、サブ（git worktree）の3つを並行で動かす
- **使う条件**：着手時に、元のフォルダで動いている claude セッションを数え、自分のほかに居るときだけサブを使う
- **サブの作り方**：専用の git worktree（`../cdt-<Issue番号>`）を切り、`EnterWorktree`（`path` 指定）で入る。`cd` では移れない
- **ターン末ゲート**：Stop hook の入力の `cwd` が指す作業ツリーを検査する

## 採用理由（なぜこれを選んだか）

別セッションの `git switch` が自分のコミットを動かすのは、同じ作業ツリーを使っているときだけである。専用の worktree なら作業ツリーも `HEAD` も自分だけのものになり、別セッションが切り替えても、自分のコミットは動かない。

あとから来るセッションも着手時に同じ数え方をして自分の worktree へ分かれるので、先にメインで作業しているセッションは巻き込まれない。単独で動くときは、worktree の作成と依存のインストールの手間を払わずに済む。

## 検討した代替案（なぜ却下したか）

**決定の軸：別セッションの `git switch` から、自分のコミットをどう守るか。**

| 案                               | 内容                                                             | 却下理由                                                                             |
| -------------------------------- | ---------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| 常に worktree を使う             | —                                                                | 単独で動くときも worktree の作成と依存のインストールの手間がかかり、守る相手が居ない |
| 検知して人間に頼む               | 別セッションを検知したら、人間に worktree 内での起動し直しを頼む | 検知のたびに人間の手間が残る。AI は `EnterWorktree` で自分で入れる                   |
| コミット直前にブランチを確認する | 共有の作業ツリーのまま、コミットの前にいまのブランチを確かめる   | 3回破られた（#638・#678・#808）                                                      |

## トレードオフ・影響

| 受け入れる制約・リスク                                                      | 影響範囲                       | 緩和策                                                                             |
| --------------------------------------------------------------------------- | ------------------------------ | ---------------------------------------------------------------------------------- |
| 同時に着手した2つのセッションが互いを数えられず、両方がメインで作業しうる   | —                              | コミット時の同じ数え方で、コミットの巻き込みは抑える。ブランチの切り替えは防げない |
| 人間が端末で行う `git switch` は、claude セッションではないので数えられない | メインで作業するセッション     | なし                                                                               |
| 数えるのは claude プロセスなので、編集していないセッションも数える          | 単独のつもりで worktree を使う | 安全側に倒れるだけで実害は無い。`lsof` が使えず数えられないときも、居る扱いにする  |
