# ドキュメント規約の例外ログ

ドキュメントの規約をあえて守らないと決めたとき、その判断を1行ずつ残す。本文に理由を書く代わりの置き場である。

点検する側は、点検を始める前に対象ファイルのパスでこの表を検索する。該当する行があれば、その規定を再び指摘しない。

## 何を入れるか

| 入れる                                                                        | 入れない                                                                                     |
| ----------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 特定の1文書についての一回きりの判断（例：この表だけ列の上限を超えたまま置く） | 文書種別ごとの類型的な例外（例：要件定義書では表と文章の重複を許す）。点検側の判定基準に書く |

判断のもとになった外形的な事実（列数・行数など）を「判断」列に書く。前提が変われば、その行はもう当てはまらないと読み手が気づけるようにするためである。
