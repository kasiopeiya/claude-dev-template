# docs/ の置き場所定義

`docs/` に新しい文書を作る AI が、どのサブディレクトリに置くかを決めるときに引く。

| ディレクトリ      | 対象読者                        | 置くもの                                                                                                                              |
| ----------------- | ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `adr`             | AI・人間                        | ADR                                                                                                                                   |
| `design`          | AI・人間                        | 設計書                                                                                                                                |
| `guide`           | 主に人間（AI が読むこともある） | 人間の理解を促す資料                                                                                                                  |
| `policy`          | AI                              | AI の判断基準                                                                                                                         |
| `project-context` | AI                              | このプロジェクト固有の事実：背景・前提・用語など、AI が知らないこと。他のプロジェクトへ持ち出せるものは置かない（それは `reference`） |
| `reference`       | AI                              | AI が作業中に引いて照合する資料：定義・カタログ・規約・チェックリスト・記録。判断が割れる事柄への立場は持たない（それは `policy`）    |
| `runbook`         | 主に人間                        | 手順書                                                                                                                                |
