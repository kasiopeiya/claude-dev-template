# レビューレポートフォーマット

`/doc-review` が Phase 3 で、各レンズの結果を統合して出すときの書式。観点の判定基準は review-criteria.md に置く。

点数・良い点・総評は、どの欄にも書かない。結果を使う側（/design など）は指摘の有無と severity だけで直すかを決めており、良い点を求めると、見る観点の少ないレビューでは良い点のでっち上げを招く。

## レポート全体

```
## Doc Review Report

<!-- Issue 情報を受け取ったときだけ、次の1行を置く -->
**レビューコンテキスト**: Issue #<番号>「<タイトル>」に基づく更新のレビュー

### 🔍 レンズごとの判定した観点

<!-- レンズごとに1行。各レンズの生レポートにある「判定した観点」をそのまま転記する。転記漏れがあると、次の「未判定の観点」が信頼できなくなる。起動条件に当てはまらず起動しなかったレンズは「起動せず（対象の文書なし）」と書く -->

| レンズ | 判定した観点 |
| --- | --- |
| <レンズ名> | <列挙> |

### ❓ 未判定の観点

<!-- review-criteria.md の観点一覧の全行のうち、上の表のどこにも名前が挙がっていないものを列挙する。起動しなかったレンズの担当観点は入れない（各文書の表で「対象外」と書く）。無ければ「なし」 -->

- <観点名>（無ければ「なし」）

### 🚦 合否

<!--
合否の判定基準は ai-review-gate-policy（../../../../docs/policy/ai-review-gate-policy.md）「合格条件は『残してよい例外以外のCriticalが0件』」。
ここで数える Critical は、対象の全文書を通じた合計から、このレビュー内で「食い違いの裁定」により issue:needs-human-decision として起票した件数を引いたもの。
呼び出し側（/design 等）が別に持つ除外（例：Issue の意図に反してスキップした指摘）は、この判定に含めない。呼び出し側がその除外を反映して合否を決め直す。
-->

- **判定**: <🚫 要修正 / ✅ 合格>
- **Critical残数**: <上の計算による件数>
- **Issue にして残す Critical**: <issue:needs-human-decision として起票した Issue 番号と概要。無ければ「なし」>

---

<!-- 対象文書ごとに、ここから「繰り返しここまで」までを繰り返す -->

## 文書: `<ファイルパス>`

### 📁 文書情報
- **判定した範囲**: <差分 / 全文>（差分なら、前からある違反は判定していない。全文の判定は `--full`）
- **種別**: <doc-types.md の種別>
- **人間向け文書**: <はい / いいえ>
- **最終更新**: <git log による最終コミット情報>

### 📋 観点ごとの判定

<!--
review-criteria.md の観点一覧を上から順に全行書き出す（行を省かない）。観点名は一覧の行名と一字一句同じにする。
判定は 準拠 / 違反 / 対象外 / 未判定 のいずれか。違反の行には、下の「改善が必要な点」に出した指摘の数を書く。
-->

| 観点 | 判定 | 指摘の数 |
| --- | --- | --- |
| <観点一覧の行名> | <準拠 / 違反 / 対象外 / 未判定> | <違反なら件数、それ以外は -> |

---

### 🔧 改善が必要な点

#### 🚨 Critical
<!-- 無ければ「なし」 -->

- **<観点名>**: <具体的な問題の説明>
  - **場所**: <節名>（`<ファイルパス>:<行番号>`）
  - **引用**: <対象文書からコピーした原文1〜3行。欠落の指摘なら、欠落を確認した範囲の原文。判定範囲が差分なら、原因になった差分の行（削除した行は差分の `-` の行）>
  - **改善案**: <具体的な改善方法。レンズ間で食い違った場合は裁定で採った案を書き、捨てた案と根拠の条文を添える>
  - **理由**: <なぜ問題か>

#### ⚠️ High
<!-- 無ければ「なし」 -->

（書式は Critical と同じ）

#### 💡 Medium
<!-- 無ければ「なし」 -->

（書式は Critical と同じ）

---

### 🚀 次のステップ（優先度付き）

<!-- 指摘が無ければ「なし」と書く -->

1. **[高] <Critical の指摘の観点名>**: <改善案を1行で>
2. **[中] <High の指摘の観点名>**: <改善案を1行で>
3. **[低] <Medium の指摘の観点名>**: <改善案を1行で>

<!-- 繰り返しここまで -->
```

複数の文書をレビューしたときは、この後に「全体サマリー」を出す。最後に1回だけ `**レビュー完了**` と書く。

## 全体サマリー（複数の文書をレビューしたとき）

各文書のレポートをすべて出した後に1回だけ出す。

```
## Doc Review Summary

| 文書 | 種別 | Critical | High | Medium |
| --- | --- | --- | --- | --- |
| `<ファイルパス>` | <種別> | <件数> | <件数> | <件数> |

### 🚀 次のステップ（全文書横断・優先度付き）

<!-- 各文書の「次のステップ」を severity 順（Critical→High→Medium）に並べ直す -->
```
