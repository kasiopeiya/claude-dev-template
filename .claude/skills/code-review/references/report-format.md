# レビューレポートフォーマット

`/code-review` が Phase 3 で、各レンズの結果を統合して出すときの書式。観点の判定基準は review-criteria.md に置く。

点数・総合評価・良い点は、どの欄にも書かない。結果を使う側（/code-dev など）は指摘の有無と severity だけで直すかを決めており、良い点を求めると、見る観点の少ないレビューでは良い点のでっち上げを招く。

## レポート全体

```

### 🔍 レンズごとの判定した観点

<!-- レンズごとに1行。各レンズの生レポートにある「判定した観点」をそのまま転記する。転記漏れがあると、次の「未判定の観点」が信頼できなくなる -->

| レンズ | 判定した観点 |
| --- | --- |
| <レンズ名> | <列挙> |
```
