# レビューレポートフォーマット

`/cdk-review` が Phase 3 で、各レンズの結果を統合して出すときの書式。**先に [`.claude/rule-bodies/review-integration.md`](../../../rule-bodies/review-integration.md) の「レポートの共通の欄」を Read し、下の `<!-- 共通の欄 … -->` の位置に、その書式の欄を出す。**

## レポート全体

出力順は次のとおり：ヘッダー（判定した観点・未判定の観点・合否）→ ファイルごとのレポート×N → 全体サマリー（複数ファイルのとき）→ 設計書レビュー（対象があるとき）。

